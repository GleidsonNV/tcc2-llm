# LLM Requirements Chatbot Project

LLM chatbot that generates functional requirements

## Tech Stack

- **Backend**: Next.js/ ai vercel sdk
- **Model**: mistral-small-latest
- **Web Framework**: Next.Js
- **Frontend**: HTML, CSS
- **Environment**: Docker

## Prerequisites

Before you get started, ensure that you have the following installed:

- NodeJs
- Docker 
- A valid free Mistral API key (you can get it from [Mistral's platform](https://docs.mistral.ai/api/)).
